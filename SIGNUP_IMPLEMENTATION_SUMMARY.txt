================================================================================
                            KEY SPECIFICATIONS
================================================================================

ENDPOINT:               POST /api/auth/sign-up
PURPOSE:               Register new users with email and password
SUCCESS STATUS CODE:   201 Created (not 200)
AUTHENTICATION:        Not required (public endpoint)
RATE LIMIT:            10 attempts per 15 minutes per IP

REQUEST BODY:
  {
    "email": "user@example.com",
    "password": "SecurePassword123"
  }

RESPONSE (201 Created):
  {
    "user": {
      "id": "uuid",
      "email": "user@example.com",
      "email_confirmed_at": null
    },
    "session": {
      "access_token": "jwt_token",
      "refresh_token": "refresh_token",
      "expires_in": 3600,
      "token_type": "bearer"
    }
  }

ERROR CODES:
  - 400: VALIDATION_ERROR (invalid email, empty password, missing fields)
  - 409: EMAIL_EXISTS (email already registered)
  - 422: WEAK_PASSWORD (password doesn't meet strength requirements)
  - 429: RATE_LIMITED (too many registration attempts)
  - 500: SERVER_ERROR (Supabase unavailable or unexpected error)

# Successful sign-up (expect 201)
curl -X POST http://localhost:3000/api/auth/sign-up \
  -H "Content-Type: application/json" \
  -d '{"email": "user@example.com", "password": "Pass123!"}'

# Duplicate email (expect 409)
curl -X POST http://localhost:3000/api/auth/sign-up \
  -H "Content-Type: application/json" \
  -d '{"email": "user@example.com", "password": "Different456!"}'

# Invalid email (expect 400)
curl -X POST http://localhost:3000/api/auth/sign-up \
  -H "Content-Type: application/json" \
  -d '{"email": "notanemail", "password": "Pass123!"}'

# Empty password (expect 400)
curl -X POST http://localhost:3000/api/auth/sign-up \
  -H "Content-Type: application/json" \
  -d '{"email": "user2@example.com", "password": ""}'

# Rate limit test (expect 429 after 10 requests)
for i in {1..15}; do
  curl -X POST http://localhost:3000/api/auth/sign-up \
    -H "Content-Type: application/json" \
    -d "{\"email\": \"user$i@example.com\", \"password\": \"Pass123!\"}"
done

================================================================================
                        DATABASE AUTO-CREATION
================================================================================

When sign-up succeeds, Supabase Auth automatically creates:

1. auth.users table:
   - id (UUID)
   - email (unique, indexed)
   - encrypted password (bcrypt)
   - email_confirmed_at (null until verified)
   - created_at, updated_at timestamps

2. public.profiles table (via trigger):
   - user_id (foreign key)
   - timezone (default: UTC)
   - created_at, updated_at

3. public.preferences table (via trigger):
   - user_id (foreign key)
   - active_categories (all available)
   - report_dow (1 = Monday)
   - report_hour (8 = 8 AM UTC)
   - preferred_delivery_channels: ["in_app"]
   - max_daily_notes (default value)
   - email_unsubscribed_at (null)
