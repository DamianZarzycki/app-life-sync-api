## How It Works

### Input
- **Request Body**: ✅ NONE (no input needed!)
- **Query Parameters**: ✅ NONE
- **Headers**: ✅ Only `Authorization: Bearer <JWT>`

### Processing (12 Steps)
```
1. Authenticate user
2. Create Supabase & OpenRouter clients
3. Fetch user's active_categories from preferences
4. Validate active categories exist
5. Fetch user's timezone from profile
6. Validate categories exist in system
7. Check weekly limit (3 reports max)
8. Fetch all notes from active categories
9. Verify notes exist
10. Call OpenRouter LLM to generate report
11. Save report to database with generated_by: 'scheduled'
12. Return 201 Created with Location header
```

### Output

**Success (201 Created)**:
```json
{
  "id": "report-uuid",
  "user_id": "user-uuid",
  "generated_by": "scheduled",
  "html": "<html>Analyzed report...</html>",
  "text_version": "Plain text version...",
  "llm_model": "google/openai/gpt-4o-mini",
  "system_prompt_version": "v1.0",
  "categories_snapshot": [...],
  "created_at": "2025-11-11T10:30:00Z"
}
```

**Silent Skip (204 No Content)**:
Returned when:
- No active categories selected
- No notes available
- Weekly limit reached
- Category validation fails
- Any data not found (graceful degradation)

## Key Features

### ✨ Silent Skipping
Instead of returning errors for normal conditions, this endpoint returns `204 No Content` so it can be safely called by scheduled tasks (cron jobs) without error handling:

```typescript
if (!activeCategories || activeCategories.length === 0) {
  console.log(`[INFO] User ${userId} has no active categories, skipping auto report`);
  res.status(204).send();  // ← Silent skip
  return;
}
```

### 🛡️ Weekly Limit Enforcement
Counts BOTH on-demand and scheduled reports together:
```typescript
.in('generated_by', ['on_demand', 'scheduled'])
```

Prevents users from generating too many reports by mixing types.

### ⏰ Timezone-Aware Week Calculation
```typescript
const now = new Date();
const userDate = new Date(now.toLocaleString('en-US', { timeZone: timezone }));
// Calculate Monday-Sunday boundaries in user's local timezone
```

### 🧠 OpenRouter Integration
Passes notes grouped by category to LLM:
```typescript
reportContent = await openRouterService.generateWeeklyReport(
  notes,              // All notes from active categories
  validatedCategories,// With metadata
  { timezone }        // User context
);
```

## Usage Examples

### Example 1: Simple Fetch Request
```javascript
const response = await fetch('https://api.example.com/api/reports/generate-auto', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${userToken}`,
  }
});

if (response.status === 201) {
  const report = await response.json();
  console.log('📊 Report generated:', report.id);
} else if (response.status === 204) {
  console.log('⏭️  Skipped (no active categories or notes)');
}
```

### Example 2: Scheduled Cron Job (Node.js)
```javascript
import cron from 'node-cron';
import { getAllUserTokens } from './auth';

// Every Monday at 8 AM
cron.schedule('0 8 * * 1', async () => {
  const users = await getAllUserTokens();
  
  for (const user of users) {
    const res = await fetch('/api/reports/generate-auto', {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${user.token}` }
    });
    
    console.log(`User ${user.id}: ${res.status}`);
    // 201 = created, 204 = skipped, both are fine!
  }
});
```

### Example 3: Error Handling
```typescript
async function generateAutoReport(token: string): Promise<void> {
  try {
    const res = await fetch('/api/reports/generate-auto', {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${token}` }
    });

    switch (res.status) {
      case 201:
        const report = await res.json();
        console.log('✅ Report created:', report.id);
        break;
      case 204:
        console.log('⏭️  Skipped (no active categories or notes)');
        break;
      case 401:
        console.error('❌ Not authenticated');
        break;
      case 409:
        const error = await res.json();
        console.error('❌ Weekly limit reached:', error.error.details);
        break;
      case 500:
        console.error('❌ Server error');
        break;
    }
  } catch (err) {
    console.error('❌ Network error:', err);
  }
}
```
