# Auto Report Generation - Quick Reference

## Endpoint
```
POST /api/reports/generate-auto
Authorization: Bearer <JWT>
```

## What It Does
- 📋 Reads user's **active_categories** from preferences
- 📍 Gets user's **timezone** from profile  
- 📝 Fetches all **notes from those categories**
- 🧠 Sends to **OpenRouter LLM** for analysis
- 💾 Saves report as **generated_by: 'scheduled'**

## Responses

### ✅ Success (201 Created)
```json
Location: /api/reports/{id}
{
  "id": "uuid",
  "generated_by": "scheduled",
  "html": "<html>...</html>",
  "text_version": "...",
  ...
}
```

### ⏭️ Silent Skip (204 No Content)
Happens when:
- User has no preferences
- No active categories selected
- No notes in active categories
- Weekly limit reached (3 reports/week)
- Any data validation fails

### ❌ Errors
- **401**: Not authenticated
- **409**: Weekly limit reached (with details)
- **500**: Unexpected error

## How It Differs From Other Endpoints

| Feature | POST /generate | POST /generate-auto |
|---------|---|---|
| Input | `include_categories` in body | None (uses preferences) |
| Categories | User specifies | From `preferences.active_categories` |
| Timezone | From profile | From profile |
| Weekly Limit | Yes (3 max) | Yes (3 max) |
| Generated By | `on_demand` | `scheduled` |
| Silent Skip | No (error) | Yes (204) |

### JavaScript
```javascript
const response = await fetch('/api/reports/generate-auto', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${userToken}`,
    'Content-Type': 'application/json'
  }

if (response.status === 201) {
```

### TypeScript with Fetch
```typescript
interface GenerateAutoReportResponse {
  status: 201 | 204 | 401 | 409 | 500;
  report?: ReportDto;
  error?: ErrorResponseDto;
}

async function generateAutoReport(token: string): Promise<GenerateAutoReportResponse> {
  const res = await fetch('/api/reports/generate-auto', {
    method: 'POST',
    headers: { 'Authorization': `Bearer ${token}` }
  });

  if (res.status === 201) {
    return { status: 201, report: await res.json() };
  } else if (res.status === 204) {
    return { status: 204 };
  }
  
  return { status: res.status as any, error: await res.json() };
}
```

## Key Behavior

### Silent Skip vs Error
```
Scenario: User has no notes

Traditional endpoint:  ❌ Returns error
Auto-generate:        ✅ Returns 204 (silent skip)

Why? Auto-generated reports can be triggered by cron jobs,
so we don't error on normal conditions.
```

### Weekly Limit
Counts BOTH `on_demand` AND `scheduled` reports:
```typescript
in('generated_by', ['on_demand', 'scheduled'])
```

So a user can have:
- 2 on-demand reports + 1 scheduled report = 3/3 ✓ (full)
- 3 on-demand reports = 3/3 ✓ (full)
- 1 on-demand + 1 scheduled + 1 auto = 3/3 ✓ (full)

## Database Tables Involved

### Read
- `preferences` → `active_categories`
- `profiles` → `timezone`
- `categories` → validate active categories
- `notes` → fetch notes from active categories

### Write
- `reports` → insert new report with `generated_by: 'scheduled'`

## Performance Considerations

- Fetches max 100 notes (limit in code)
- Validates categories exist in system
- Week boundary calculation done in-app (not DB)
- Single LLM call regardless of note count

## Debugging

### Check if user has active categories
```sql
SELECT active_categories FROM preferences WHERE user_id = '{user_id}';
```

### Check if categories exist
```sql
SELECT id, name FROM categories WHERE active = true;
```

### Check notes available
```sql
SELECT COUNT(*) FROM notes 
WHERE user_id = '{user_id}' 
AND category_id = ANY('{active_categories}'::uuid[])
AND deleted_at IS NULL;
```

### Check weekly limit
```sql
SELECT COUNT(*) FROM reports
WHERE user_id = '{user_id}'
AND generated_by IN ('on_demand', 'scheduled')
AND created_at >= '{week_start}'
AND created_at <= '{week_end}';
```
