KEY IMPLEMENTATION DETAILS
================================================================================

SERVICE METHODS (6 core methods):
  1. getDashboard(userId, query) - Main orchestrator
  2. getUserPreferences(userId) - Fetch active categories
  3. getProfileTimezone(userId) - Get default timezone
  4. getNotesCounts(userId, since, activeCategories) - Category aggregation
  5. calculateStreak(userId) - Consecutive day calculation
  6. getRecentReports(userId) - Fetch report metadata

VALIDATION:
  - timezone: Optional IANA timezone string
  - since: Optional ISO date (YYYY-MM-DD), must be past/today

ERROR CODES:
  - 400: VALIDATION_ERROR - Invalid query parameters
  - 401: UNAUTHORIZED - Missing or invalid authentication
  - 500: SERVER_ERROR - Server-side errors

RESPONSE STRUCTURE:
  {
    "summary": {
      "active_categories": ["uuid", ...],
      "notes_count": {"uuid": count, ...},
      "streak_days": number
    },
    "recent_reports": [
      {"id": "uuid", "generated_by": "scheduled", "created_at": "ISO"}
    ]
  }

CACHING:
  - HTTP Cache-Control: private, max-age=300 (5 minutes)
  - Invalidation triggers: note CRUD, report generation
  - Optional Redis cache for high-load scenarios

PERFORMANCE TARGETS:
  - P50: < 200ms (cached)
  - P95: < 500ms (cache miss)
  - P99: < 1000ms (worst case)

ALGORITHM HIGHLIGHTS
================================================================================

STREAK CALCULATION:
  1. Query distinct note dates (past 90 days)
  2. Sort by date descending
  3. Count consecutive days from today backward
  4. Break on first gap
  
  Edge cases handled:
  - No notes → 0
  - Notes in past only → 0
  - All dates consecutive → total count

TIMEZONE HANDLING:
  - Query param timezone or profile default
  - Use AT TIME ZONE $timezone in SQL
  - Date calculations in user's local timezone
  - Midnight boundary in user's timezone

================================================================================
DATABASE QUERIES (5 total)
================================================================================

Query 1: User Preferences
  SELECT active_categories FROM preferences WHERE user_id = $1

Query 2: Profile Timezone (optional)
  SELECT timezone FROM profiles WHERE user_id = $1

Query 3: Count Notes per Category
  SELECT category_id, COUNT(*) 
  FROM notes 
  WHERE user_id = $1 AND deleted_at IS NULL AND created_at >= $2
  GROUP BY category_id

Query 4: Calculate Streak
  SELECT DISTINCT DATE(created_at AT TIME ZONE $timezone)
  FROM notes 
  WHERE user_id = $1 AND deleted_at IS NULL
  ORDER BY DATE(...) DESC

Query 5: Get Recent Reports
  SELECT id, generated_by, created_at
  FROM reports 
  WHERE user_id = $1 AND deleted_at IS NULL
  ORDER BY created_at DESC LIMIT 10
